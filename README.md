# Final AI Academic Advisor — Streamlit Prototype

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Features
- Natural-language course-name input
- RAG retrieval over the cleaned academic data
- Source/evidence display
- Ambiguity handling
- Conflict handling
- Student-specific prerequisite eligibility
- Multi-turn grade follow-up
- Missing-information handling
- Synthetic student profiles only

The application is a demonstration decision-support system, not an official university registration system.
